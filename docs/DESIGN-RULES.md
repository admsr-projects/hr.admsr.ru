# Правила дизайна кадрового портала

Единые правила для всех страниц и компонентов фронтенда (`frontend/app`).
**Перед созданием или доработкой любого интерфейса прочитайте этот файл.** Если нужен размер, цвет или
скругление, которых здесь нет, — не добавляйте новое, а выберите ближайшее из списка. Если правило мешает,
сначала правим правило здесь, затем код.

Эталон оформления — макет страницы органа (заголовок, меню раздела слева, серые панели, карточки).
Правила ниже заменяют старые заметки в `DESIGN-SYSTEM-MIGRATION.md` и `UX-DESIGN-RECOMMENDATIONS.md`.

---

## 1. Принцип: SOFT (мягкий дизайн)

Интерфейс спокойный и «мягкий»: объекты отделяются друг от друга **тоном фона**, а не линиями и тенями.

1. **Тональные поверхности вместо рамок.** Карточка — это серая панель (`bg-elevated`), а не белый прямоугольник с контуром.
2. **Без теней.** Тень допустима только у всплывающих слоёв (меню, подсказка, диалог, уведомление) — их рисует Nuxt UI.
3. **Мягкие акценты.** Метки, вторичные кнопки и предупреждения — вариант `soft` (приглушённый фон цвета + цветной текст), а не `solid`/`outline`.
4. **Один главный акцент на экран.** Заполненная (`solid`) кнопка основного цвета — только для главного действия блока («Откликнуться», «Отправить»).
5. **Мягкие скругления** (см. §4) — никаких «таблеток» у кнопок и острых углов у панелей.
6. **Спокойное движение.** Смена цвета фона при наведении, 150–200 мс. Без масштабирования, подъёма и сдвигов. Учитывать `prefers-reduced-motion`.
7. **Воздух.** Отступы из шкалы (§5), ничего не «слипается».

Границы допустимы только: у полей ввода, у разделителей (тонкая линия `border-default`), у левой линии меню раздела и у пунктирной области загрузки файла.

## 2. Типографика

Шрифт один — Inter. Корневой размер 16px, поэтому классы Tailwind дают точные значения.
**Разрешены только эти размеры** (макет использует именно их):

| Роль | Класс / токен | Размер / строка | Начертание | Где |
|---|---|---|---|---|
| Заголовок страницы H1 | `text-h1` (то же `text-display`) | 36/40 (на телефоне 28/32) | bold | Один на странице, `DsStandardPageHeader` |
| Hero главной | `text-4xl sm:text-5xl` | 36 → 48 | bold | **Только** главный экран главной |
| Заголовок раздела H2 | `text-h2` | 20/28 | bold | `DsSectionHeading`, заголовки блоков на главной |
| Заголовок карточки / панели H3 | `text-h3` | 18/28 | medium | `DsPanelCard`, заголовки крупных карточек |
| Название элемента списка | `text-base font-semibold` | 16/24 | semibold | Название вакансии, новости, документа |
| Основной текст | `text-body` (= `text-base`) | 16/24 | regular | Абзацы, описание страницы |
| Вторичный текст | `text-caption` (= `text-sm`) | 14/20 | regular / medium | Подписи, факты, дата, меню, кнопки, поля |
| Мелкий текст | `text-overline` (= `text-xs`) | 12/16 | medium | Хлебные крошки, служебные пометки |

Запрещено: `text-2xl`, `text-3xl`, `text-6xl` и выше; произвольные размеры `text-[15px]`, `text-[17px]`;
`tracking-tight`; в одном блоке больше трёх размеров. Жирность — только `font-medium` (500), `font-semibold` (600), `font-bold` (700).
Цвета текста: основной `text-text-primary`, приглушённый `text-text-muted`. Не использовать `text-gray-*`, `dark:text-white` и шестнадцатеричные цвета.

---

## 3. Цвет

Все цвета — через токены (`assets/css/tokens/colors.css`), чтобы работали светлая и тёмная темы.

| Назначение | Токен / класс |
|---|---|
| Фон страницы | `bg-default` |
| Панель, карточка (уровень 1) | `bg-elevated` |
| Элемент внутри панели (уровень 2) | `bg-default` |
| Наведение на панель | `hover:bg-accented` |
| Основной текст | `text-text-primary` |
| Приглушённый текст | `text-text-muted` |
| Акцент (ссылки, активный пункт, главная кнопка) | `text-primary`, `bg-primary` |
| Разделитель | `border-default` |

Статусы — только через `color` компонента Nuxt UI в варианте `soft`: `success`, `warning`, `error`, `info`.
Контраст текста — не ниже 4.5:1 (WCAG AA). Приглушённый текст не светлее токена `text-text-muted`.

---

## 4. Скругления

| Что | Класс |
|---|---|
| Кнопки и метки (`UBadge`) | `rounded-md` (6px) |
| Поля ввода, мелкие плашки внутри панелей | `rounded-lg` (8px) |
| Панели и карточки | `rounded-xl` (12px) |
| Меню раздела | `rounded-md` (6px) |
| Аватары и круглые иконки | `rounded-full` |

Запрещено: `rounded-2xl`, `rounded-3xl`, `rounded-full` у кнопок и меток. Кнопки и метки получают скругление из
`app.config.ts` (`rounded-md`) — отдельно его не задавать.

---

## 5. Отступы (сетка 4px)

Использовать стандартные утилиты Tailwind (`p-4` = 16px, `gap-6` = 24px).

| Что | Значение |
|---|---|
| Между блоками страницы | `gap-4` (16) |
| Внутри карточки | `p-6` (24); шапка панели `px-6 py-4`, тело `px-6 pb-6` |
| Между заголовком и содержимым | `mb-4` (16) |
| Между меню раздела и контентом | `gap-6` (24) |
| Между строками списка | `gap-3` (12) или `gap-4` (16) |
| Иконка и текст | `gap-1.5` / `gap-2` |

---

## 6. Раскладка

- Контейнер: `ds-container`, максимум 1440px (`--ui-container`), боковые отступы 16 / 24 / 32px.
- Страница раздела: `DsStandardPage` — меню раздела слева (282px, `DsSectionSidebar`), справа заголовок, действия и содержимое.
  Хлебные крошки сверху. На телефоне меню раздела — горизонтальная полоса под шапкой, над крошками.
- Сетки карточек: 1 колонка на телефоне, 2 — от `sm`, 3 — от `lg`, зазор `gap-4`.
- Страница без меню (новость): колонка по центру `max-w-3xl`.
- Один `<main>` на странице (в `app.vue`). Внутри страниц — обычные `div`/`section`.

---

## 7. Компоненты Nuxt UI

Глобальные значения заданы в `app.config.ts`, поэтому **не переопределять их на месте**: не писать `size="lg"`,
`rounded-full`, `variant="outline"` и т. п.

| Компонент | Правило |
|---|---|
| `UButton` | Главное действие — `color="primary"` (solid). Остальные — `color="neutral" variant="soft"`. Ссылочные — `variant="link"`. Размер по умолчанию (md, 36px). |
| `UBadge` | Всегда `variant="soft"`, цвет по смыслу. |
| `UCard` | Вариант `soft` (серая панель). Не добавлять рамку и тень. |
| `UAlert` | `variant="soft"`. |
| Поля ввода | Размер по умолчанию; контур у поля — единственное место, где граница обязательна. Подпись над полем, обязательные помечать `DsRequiredLabel`. |
| `UTabs` | `variant="link"`, только текст без иконок. |
| Всплывающие подсказки | Описание раздела — иконка `i-lucide-info` рядом с заголовком (`DsSectionHeading`), а не абзац под ним. |

Готовые компоненты проекта: `DsStandardPage`, `DsSectionHeading`, `DsPanelCard`, `DsInfoCard`, `DsBlurredImage`,
`NewsCard`, `VacancyCard`. Сначала использовать их, новый компонент — только если подходящего нет.

---

## 8. Иконки и изображения

- Иконки — набор Lucide (`i-lucide-*`). Размеры: `size-4` (16) в тексте, `size-5` (20) у кнопок и пунктов, `size-6` (24) в карточках.
- Декоративная иконка — `aria-hidden="true"`. Иконка-кнопка обязательно с `aria-label`.
- Фото новостей — в `DsBlurredImage`: контейнер всегда одной пропорции (16:9), фото целиком, позади размытая копия.
- У содержательных изображений `alt` описывает смысл; у декоративных `alt=""`.

---

## 9. Доступность

- Контраст текста ≥ 4.5:1, крупного ≥ 3:1. Не передавать смысл только цветом.
- Весь интерфейс доступен с клавиатуры, виден фокус (`focus-visible`), порядок Tab логичен.
- У каждого поля есть подпись; у навигаций — `aria-label`; у списков страниц (пагинация) — уникальная подпись.
- Вёрстка не ломается при масштабе 200% (зум браузера), горизонтальной прокрутки страницы нет.
- Ссылки внутри текста подчёркнуты.

---

## 10. Чек-лист перед коммитом

1. Размеры шрифта только из §2, цвета только токены, скругления из §4.
2. Нет рамок и теней у карточек; поверхности — `bg-elevated` / `bg-default`.
3. Кнопки: одна главная `solid`, остальные `soft`; без `size="lg"` и `rounded-full`.
4. Отступы кратны 4px и взяты из §5.
5. Проверено в светлой и тёмной теме, на ширинах 375 / 720 / 1440 без горизонтальной прокрутки.
6. Новое правило, которого не хватило, — дописано в этот файл.
