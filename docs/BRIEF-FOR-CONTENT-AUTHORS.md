# Памятка авторам материалов для кадрового портала

Для тех, кто готовит презентации, обзоры и справочные материалы для hr.admsr.ru (в том числе с помощью нейросетей).

## 1. Что присылать

**Нужен контент, а не готовая вёрстка.** Оформление, меню, поиск и адаптацию под телефон и информационный киоск делает портал.
Готовая HTML-страница со своим дизайном на портал не встаёт: её приходится пересобирать вручную.

Присылайте:

- **текст** — Word или Markdown: заголовки разделов, абзацы, списки;
- **таблицы и перечни** — Excel или JSON: одна строка — одна запись, у каждой записи колонка «пункт акта» (например, «п. 4.5»);
- **нормативная база** — названия актов с датой и номером, ссылки на редакции;
- **дата актуальности** — на какую дату сверены акты и кто сверял.

Не присылайте: выгрузки «дашбордов» с вшитыми шрифтами, скриптами и картинками (base64), PDF вместо исходных данных.

## 2. Если всё же нужна готовая страница или презентация

Оформление — по [`DESIGN-RULES.md`](DESIGN-RULES.md), дизайн **SOFT**. Коротко:

| Что | Правило |
|---|---|
| Шрифт | Inter, один на весь материал |
| Размеры текста | 12, 14, 16, 18, 20 и 36 px. Других нет |
| Начертание | 500, 600 или 700 |
| Фон страницы | `#FAFAFA`; панели и карточки — `#F4F4F5` |
| Текст | основной `#18181B`, приглушённый `#5F5F68` |
| Акцент | индиго `#6366F1`; одна заливная кнопка на экран, остальные — «мягкие» (светлый фон, цветной текст) |
| Различие категорий | только индиго, фиолетовый, бирюзовый, изумрудный, янтарный, серо-синий; смысл всегда подписан текстом |
| Скругления | кнопки и метки — полностью круглые; поля — 8 px; панели и карточки — 12 px |
| Рамки и тени | нет. Карточки отделяются тоном фона, а не линиями. Тонкая линия — только разделитель строк таблицы |
| Градиенты, декор | нет |
| Анимация | только смена цвета фона при наведении, 150–200 мс |
| Контраст | текст не ниже 4.5:1; смысл не передавать только цветом |
| Ширина | материал должен читаться на экранах 375, 720 и 1440 px без горизонтальной прокрутки |

Нельзя: собственное боковое меню, поиск по странице, кнопки экспорта, загрузку файлов, формы, внешние шрифты и скрипты, эмодзи как иконки.
Иконки — набор Lucide.

### Готовый запрос для нейросети

```
Оформи материал для сайта администрации Сургутского района по правилам «SOFT».
Шрифт Inter. Размеры текста только 12, 14, 16, 18, 20 и 36 px, начертание 500, 600 или 700.
Фон страницы #FAFAFA, панели и карточки #F4F4F5, основной текст #18181B, приглушённый #5F5F68, акцент #6366F1.
Никаких рамок, теней и градиентов: блоки отделяй тоном фона. Скругления: кнопки и метки полностью круглые,
поля 8 px, карточки и панели 12 px. Одна заливная кнопка на экран, остальные кнопки и метки в светлом «мягком» виде.
Без собственного меню, поиска, экспорта и форм. Иконки Lucide. Верстка адаптивная, без горизонтальной прокрутки на ширине 375 px.
У каждого факта указывай пункт нормативного акта и дату, на которую акт сверен.
```

## 3. Перед отправкой

1. Каждое число, срок и лимит сверено с текстом акта; рядом указан пункт акта.
2. Указана дата актуальности и кто сверял (кадровая служба или юрист).
3. Разделы названы так, как они называются в акте.
4. Не осталось «служебных» кнопок и подсказок вроде «Загрузить data.json».
